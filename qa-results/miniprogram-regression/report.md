## 四、上线前必须完成的 3 件事

1. **环境变量**：生产服务器设置 `JWT_SECRET=<随机长串>`、`ADMIN_PASSWORD=<强密码>`、`CORS_ORIGIN=https://你的小程序业务域名`
2. **前端配置**：`utils/config.js` 切到 prod 环境，baseUrl 改为 `https://真实域名/api/v1`，并在微信公众平台配置 request 合法域名
3. **真机回归**：微信开发者工具跑通 登录 → 首页 → 设备列表 → 详情 → 打印 → 历史 主链路
